High-throughput, zero-allocation drop-in replacement for make.fun's `csv-reader 1.0.0`, combining a slice-based string parser (`run`) and a fused UTF-8 Buffer CSV-in-JSON streaming engine (`runCasesBuffer`) that matches every broken-row edge case identically.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
